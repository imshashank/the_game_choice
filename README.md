# QuickChoice

QuickChoice was a HackGT 2014 prototype that suggested places to visit, food to try, and music to listen to. The project is listed under its public name on [Devpost](https://devpost.com/software/quickchoice), where the original submission describes the three modes and records the team's awards.

The prototype grouped a user's interests into topics, then combined them with a request to suggest a result. For example, it used categories such as cuisine to turn a request for spicy food into candidate recommendations. The repository preserves the PHP and web interface. The old integrations were part of the hackathon prototype and have not been validated for current use.
